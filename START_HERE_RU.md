# Как запустить pet-project — краткая инструкция

Это самостоятельный проект **Video Game Sales Analytics** для портфолио Junior Data Analyst. Интерфейс и README на английском — так проект удобнее показывать рекрутерам.

## 1. Распакуй ZIP

Открой папку `video-game-sales-analytics` в VS Code, PyCharm или через терминал.

## 2. Установи зависимости

Открой терминал в папке с `app.py` и выполни:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Если PowerShell блокирует запуск скриптов, можно пропустить активацию и использовать ` .venv\Scripts\python.exe -m pip install -r requirements.txt `, а затем `.venv\Scripts\python.exe -m streamlit run app.py`.

## 3. Подключи настоящий CSV

**Я уже добавил твой настоящий `games.csv` в папку `data` внутри обновлённого ZIP.** Просто проверь, что после распаковки файл лежит по пути `data/games.csv`. Дополнительно скачивать его не нужно.

**Или**, если интернет доступен:

```powershell
python scripts/download_data.py
```

Скрипт загрузит общедоступную версию vgsales.csv из Zenodo или резервного зеркала. Если ссылки не работают — используй свой `games.csv` с Яндекс Диска.

**Примечание:** в архиве именно твой загруженный CSV, и все результаты рассчитаны по нему. При загрузке проекта на GitHub `data/games.csv` не попадёт в коммит из-за `.gitignore`. Перед публичной публикацией CSV проверь условия распространения данных.

## 4. Запусти дашборд

```powershell
streamlit run app.py
```

Открой ссылку, которую покажет терминал (обычно `http://localhost:8501`).

## 5. Получи готовые аналитические выводы и картинки

```powershell
python scripts/generate_report.py
python scripts/run_sql_analysis.py
```

**Готовые результаты уже находятся в `reports/insights.md`, `reports/sql_results.md` и `reports/figures/`.** Команды выше позволяют пересоздать их после изменения данных. Jupyter Notebook с исследованием находится в `notebooks/01_eda.ipynb`.

## 6. Проверь качество кода

```powershell
python -m pytest -q
```

## 7. Оформи GitHub

Создай репозиторий `video-game-sales-analytics`, загрузи **содержимое** этой папки, добавь 2–3 настоящих скриншота открытого Streamlit-приложения и ссылку на работающий дашборд, если опубликуешь его через Streamlit Community Cloud.

`.gitignore` уже скрывает исходный CSV, временные файлы и виртуальное окружение. Если развернёшь на Streamlit Community Cloud, данные потребуются и на сервере: либо аккуратно добавь разрешённый к распространению CSV, либо доработай приложение для загрузки файла (такая возможность уже есть в боковом меню).

## Что показывать в CV

Укажи **Python, Pandas, SQL, Plotly, Streamlit, Data Cleaning, EDA, Data Visualization**, прикрепи ссылку на GitHub. Не нужно писать, что ты предсказывал будущие продажи — в этом проекте пока нет ML и прогноза.

## Фактические результаты на твоих данных

- После очистки осталось **16 291** записей из **16 598**.
- Самая успешная платформа по суммарным продажам копий — **PS2** (1 233,46 млн).
- Ведущий издатель — **Nintendo** (1 784,43 млн).
- В разрезе Nintendo / Japan максимальный IQR — **Fighting**, а среднее Fighting **меньше**, чем у Simulation (0,830 против 0,845 млн).
- Для Nintendo / Sports крупные пики релизных когорт — **2006** и **2009** годы.

Не путай продажи игр, **выпущенных** в конкретном году, с количеством копий, **проданных** в этот календарный год.
